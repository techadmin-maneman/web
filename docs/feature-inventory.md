# Feature inventory

Every section, control and state in v2, from the front-end prompt's list. Each is ticked for the milestone that delivers it, with its evidence:

- a fidelity pair: `docs/fidelity/<width>/<name>.jpg`, the design on the left and the build on the right;
- or a browser test in `e2e/`.

✅ means done, with the milestone that did it where it was not F1. Where a later milestone adds behaviour, the item says what.

Phase 1's form, its v2 layout and `/api/lead` from the page are gone, so the `book-*` pairs are too; the landing's pairs are in `docs/fidelity/referral/`.
