# What the owner's answers of 27 September 2026 ask of the code

The owner answered every open point on 27 September 2026 (`docs/owner-answers-2026-09-27.md`). This plan turns each answer that needs code into a piece of work, says which are built and which are owed, and orders what is owed by the release that needs it (`docs/go-live.md`: the site first, the apps later). What only the owner, counsel, the CA or ops can do is in `docs/go-live.md`, not here.

Sizes are estimates for one developer: **S** under half a day, **M** one to two days, **L** three to five. Each owed piece carries its own tests and docs, as the repository asks: the rule in `src/policy/` with the words it quotes, the route in zod with `npm run openapi`, a migration with `npm run schema`, and the open point it closes moved to "Settled".

## Two standing rules

- **Every policy is an ops update, not a tech update** (ADR 0025, item 66). The console is the source of truth for every price and rule, and FSM and every other system follow it. Built on 28 September 2026 (ADR 0088; section A).
- **"Message us" only for problems** (ADR 0025, item 70). A hand-off that sends a client to WhatsApp to buy or book comes out; one about a problem stays.
