# Fidelity screenshots

The design on the left, the build on the right. `npm run fidelity` makes the public site's home page and try-on, at 390 and 1440 px; `npm run fidelity:refer` makes the referral landing's, in `referral/`, which are `/book`'s too, since it is the same page without the invite; `npm run fidelity:app` makes the client app's, in `client-app/`; `npm run fidelity:ops` makes the ops console's, in `ops/`; `npm run fidelity:tech` makes the technician app's, in `technician-app/`. Each replaces only the pairs it makes. The method, including Phase 2's boards, is in `docs/fidelity-method.md`.
